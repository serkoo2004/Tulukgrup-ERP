# Real Excel Column Map

Bu not, masaustundeki `TULUKGRUP` Excel dosyalarindan sadece kolon/rapor mantigi referans alinarak hazirlandi. Gercek satir verileri, plaka listeleri, kisi adlari ve tutarlar koda veya dokumana tasinmaz.

## Arac Listesi

Kaynak ornekler:

- `ARAÇ LİSTESİ.xlsx`
- `SATILAN ARAÇLAR 3.xlsx`
- `satılacak araçlar.xlsx`

Sisteme baglanan kolonlar:

- Firma / sirket
- Departman
- Plaka
- Marka
- Model
- Model yili
- Kullanan / zimmetli kullanici
- Arac tipi / cinsi
- Yakit turu
- Vites
- Yedek anahtar lokasyonu
- Tasitmatik firmasi
- HGS
- Mobiliz
- Kopilot
- K2
- Garanti durumu
- Garanti bitis tarihi
- Son KM
- Acik gorev
- 30 gun icinde biten police
- Durum

Sonraki veri modeline aday kolonlar:

- Tahmini satis rakami
- Satis bekleme durumu
- Satis teklif / pazar notu

## Police / Kasko / Trafik

Kaynak ornekler:

- `Kasko + Trafik+ Vize.xlsx`
- `TT FİLO KASKO TEKLİFLER.xlsx`
- `TT FİLO KASKO TEKLİFLER REVİZE EDİLDİ.xlsx`

Sisteme baglanan kolonlar:

- Plaka
- Police tipi
- Police no
- Sigorta sirketi
- Acente
- Baslangic
- Bitis
- Tutar
- Onceki tutar
- Para birimi
- Kalan gun
- Yenileme durumu

Sonraki veri modeline aday kolonlar:

- Teklif matrisi
- Onaylanan teklif
- Vize / muayene tarihi

## Hasar / Deger Kaybi

Kaynak ornekler:

- `ARAÇ DEĞER KAYBI TAKİP TABLOSU.xlsx`
- `ARAÇ KONTROLLERİ ESKİ.xlsx`
- `ARAÇ KONTROL FORMU.xlsx`

Sisteme baglanan kolonlar:

- Plaka
- Hasar tarihi
- Hasar tipi
- Aciklama
- Tahmini tutar
- Gercek tutar
- Sigorta dosya no
- Durum

Sonraki veri modeline aday kolonlar:

- Deger kaybi sureci
- Ekspertiz raporu
- Yapilanlar
- Sube / bolge

## Yakit / KM

Kaynak ornekler:

- `KÇM ARAÇ YAKIT-KM RAPORU` dosyalari

Sisteme baglanan kolonlar:

- Plaka
- Kullanici
- Son KM
- KM kayit sayisi
- Gider tipinde yakit

Sonraki veri modeline aday kolonlar:

- Aylik guncel KM
- Yakit verimlilik grafikleri

## Arac Operasyon Hizmetleri

Kaynak ornekler:

- `ARAÇ YIKAMA.xlsx`

Sonraki veri modeline aday kolonlar:

- Yikama hizmeti icin firma bazli fiyat sozlesmesi
- Aylik yikama adet/masraf ozeti

## Envanter / Malzeme

Kaynak ornekler:

- `DEPO.xlsx`
- `OFİS ENVANTER.xlsx`
- `PERSONEL ELİNDEKİLER.xlsx`
- `YANGIN TÜPLERİ.xlsx`

Bu dosyalar filo cekirdeginin disinda kalir. Proje ERP geneline genisleyince envanter/zimmet/modulune temel olabilir.
